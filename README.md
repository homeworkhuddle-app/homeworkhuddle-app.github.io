# Homework Huddle website

The website for **Homework Huddle**, an iPhone and iPad app that helps parents with primary school homework. It explains maths methods, phonics and grammar the way school teaches them.

- Website: https://homeworkhuddle-app.github.io/
- Privacy policy: https://homeworkhuddle-app.github.io/privacy.html
- Support: https://homeworkhuddle-app.github.io/support.html
- Contact: homeworkhuddle.help@outlook.com

Hosted for free with GitHub Pages. This repository holds only the website, not the app's code.
